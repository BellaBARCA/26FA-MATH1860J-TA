# MATH1860J TA Materials

Welcome to the unofficial TA resource repository for **MATH1860J – Honors Mathematics II** at SJTU-GC.

This repository contains all instructional materials, problem sets, tutorial notes, and supplementary resources prepared for the teaching assistants of the course in 26 FA. It is designed to ensure consistency across tutorial sections and to provide a centralized, version-controlled hub for course support materials.

---

## 🚀 Getting Started

### For TAs

1. **Clone the repository**
   ```bash
   git clone https://github.com/BellaBARCA/26FA-MATH1860J-TA.git
   ```
2. **Pull the latest updates** before each tutorial session:
   ```bash
   git pull origin main
   ```
3. **Submit your contributions** via pull requests or by pushing directly to the main branch (if authorized).

### For Instructors / Course Coordinators

Use this repository to:
- Distribute standardized tutorial content across all sections.
- Track changes and updates made by TAs.
- Provide feedback via GitHub Issues or pull request reviews.

---

## 📝 Content Guidelines

- All materials must be **clear, correct, and pedagogically sound**.
- Solutions should include **step-by-step reasoning** where appropriate.
- Use **LaTeX** for mathematical typesetting (we recommend Overleaf or local editors).
- Maintain consistent naming conventions (e.g., `weekXX_RC_slides.tex`, `weekXX_RC_solutions.tex`).

---

## 🤝 Contributing

We welcome contributions from all TAs. To contribute:

1. Fork the repository (if you do not have direct write access).
2. Create a new branch for your changes.
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Commit your changes with descriptive messages.
4. Push and open a pull request detailing your updates.

Please ensure your contributions do not duplicate existing content and are properly formatted.
